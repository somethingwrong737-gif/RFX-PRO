PINDI STUDIO - Setup guide (Windows 10/11, 64-bit)

1. Install Python 3.10, 3.11 or 3.13 from python.org.
   Tick "Add Python to PATH" during the install.

2. Extract this zip to a normal folder (for example C:\PindiStudio).
   Do NOT run it from inside the zip file.

3. Double-click run.bat
   - The first run downloads several GB of packages. On slow internet this can take
     30 minutes or more. Keep the black window open until the app appears.
   - You need roughly 10 GB of free disk space.

4. Voice Cloning and Voice Changer download their AI models the first time you use
   them (another 1-3 GB each). The window may look idle while this happens - wait.

5. Optional: double-click create_shortcut.bat to get a Pindi Studio icon on your
   Desktop. After that you can open the app from the icon.

6. Optional: setup_seedvc.bat installs Seed-VC, the most accurate voice changer
   (large download, slower on CPU).

Notes
- The cloning model (XTTS-v2) is licensed for NON-COMMERCIAL use only.
- Only use voices you own or have permission to use.
- Only download content you own or have permission to use.
- If something goes wrong, open pindi_log.txt in this folder (created when you start
  the app from the Desktop icon) and send it to whoever shared this with you.
